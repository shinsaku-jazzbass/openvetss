## GitHub Pages で公開する場合の注意

各ページのリンクが `/visit/...` のように**先頭スラッシュ**で書かれています。

- **ユーザーサイト**（`https://<アカウント>.github.io/`）や**独自ドメイン** … そのまま動きます
- **プロジェクトサイト**（`https://<アカウント>.github.io/openvetss/`）… リンクが壊れます

プロジェクトサイトで公開する場合は、全HTMLの `href="/` を `href="/openvetss/` に
置き換えてください。

```
grep -rl 'href="/' . --include='*.html' | xargs sed -i 's|href="/|href="/openvetss/|g'
```

本番は www.vetss-karte.net なので、そちらへ置く分は変更不要です。
