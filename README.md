# OpenVetss

動物病院のためのオープンソース・ツール群。
受付から診療記録、会計、紙カルテまでを、**サーバもインストールもなしに、タブレット1台**で通します。

> Open-source tools for veterinary clinics. Reception, SOAP records, checkout and
> printed charts — all on a single tablet, with no server and no installation.
> Single-file HTML, works offline. MIT licensed.

すぐ試せます → **https://www.vetss-karte.net/visit/**

---

## 何ができるか

| ツール | できること | ファイル |
|---|---|---|
| **受診ハブ** | カルテホルダーのQRを読み、問診・カルテ・会計を1つの受診にまとめ、診療録を印刷する | `visit/visit.html` |
| **ボタンカルテ** | 1,837件の文例をボタンで押して S・O・A・P を組み立てる | `karte/karte.html` |
| **ネットレジ** | 会計を打ち、診療明細を発行し、日計を CSV・Excel に書き出す | `netregi/netregi.html` |
| **QRラベル発行** | カルテホルダー用のQRラベルをA4に並べて印刷する | `visit/qrlabel.html` |
| **問診（整形外科）** | 日本獣医麻酔外科学会 整形外科委員会 ver.1 準拠の97項目 | `ortho/index.html` |

それぞれ単独でも動きます。受診ハブから開くと、同じ診察券番号で記録が結びつきます。

```
カルテホルダーのQR → 問診 → S・O・A・P → 会計 → 紙カルテ → ホルダーへ
```

## 設置

Webサーバに置くだけです。PHP もデータベースも要りません。

```
/
├── index.html                    トップ
├── license.html                  ライセンスのご案内
├── visit/
│   ├── index.html                受診ハブ 紹介
│   ├── visit.html                受診ハブ
│   └── qrlabel.html              QRラベル発行
├── karte/
│   ├── karte.html                ボタンカルテ
│   └── karte_master.json         文例マスタ（54分類 1,837件）
├── netregi/
│   ├── index.html                ネットレジ 紹介
│   ├── netregi.html              ネットレジ本体
│   ├── setup.html                設定ツール
│   └── guide.html                使い方
└── ortho/
    └── index.html                整形外科 検査問診
```

### 3つの約束ごと

1. **同じドメインに置くこと。** 端末内の記録を共有する仕組みなので、ドメインが分かれると連携しません。
2. **`netregi.html` の名前を変えないこと。** 受診ハブが `../netregi/netregi.html` を開きます。
3. **`https` で配信すること。** カメラ（QR読み取り）は `https` または `localhost` でないとブラウザが許可しません。

置き場所を変える場合は、`visit/visit.html` 冒頭の `TOOLS` を書き換えてください。

```js
const TOOLS = {
  Q: "../ortho/",
  K: "../karte/karte.html",
  R: "../netregi/netregi.html"
};
```

### iPad で使う場合

**ホーム画面に追加してから使ってください。** ブラウザのタブのままだと、しばらく開かないうちに保存内容が整理されることがあります。ハブと各ツールは、同じ文脈（ホーム画面アプリの中のリンク遷移）で行き来してください。

## 設定

### 営業日

夜間診療で日付をまたぐと、暦の日付で締めると記録が2日に割れます。`visit/visit.html` と `netregi/netregi.html` の冒頭で切り替えます。

```js
const DAY_START = 0;   // 0 = 暦どおり ／ 4 = 朝4時までは前日扱い
```

### 病院情報

`visit/visit.html` の `HOSPITAL`、`netregi/netregi.html` の `DEFAULT_CONFIG` を編集します。
レジの品名・消費税・端数処理は、**設定ツール（`netregi/setup.html`）で作った設定ファイルを読み込む**のが簡単です。

### 文例

`karte/karte_master.json` を書き換えれば、自院の文例になります。

```json
{ "schema": "vetss-karte-master/0.1",
  "groups": [
    { "id": 2, "n": "消化器の主訴症状", "soap": "S",
      "items": [ { "id": 2001, "t": "今日から" } ] }
  ] }
```

## データの扱い

### 端末の中だけで動きます

**通信をしません。** 入力されたものは、お使いのタブレットのブラウザ保存領域に入ります。外部へ送信する処理はありません。

### 扱う個人情報

**診察券番号と呼び名だけ**です。氏名・住所・連絡先は端末に持ちません。呼び名は飼主さんに分かるものであれば、正式なお名前でなくて構いません。

### 原本は、書き出したファイルと刷った紙です

ブラウザの保存領域は永続を保証されません。**一日の終わりに、診療録を印刷し、日計を書き出してください。** 端末の中は作業用の控えとお考えください。

### 受け渡しの形式

| スキーマ | 内容 |
|---|---|
| `vetss-visit/0.1` | 受診1件（問診・カルテ・会計をまとめたもの） |
| `vetss-karte/0.1` | S・O・A・P と押した文例のID、体重・体温 |
| `vetss-receipt/0.3` | 診療明細（明細行・税・支払） |
| `vetss-enquete/0.1` | 問診の回答（項目IDとテキスト） |
| `vetss-daybook/0.1` | 日計（伝票一覧と集計） |
| `vetss-setup/0.1` | レジの自院設定（病院情報・税・品名） |
| `vetss-karte-master/0.1` | 文例マスタ |
| `vetss-labels/0.1` | QRラベルの名簿 |

いずれも公開仕様です。他システムからの読み書きを想定しています。

## 今できないこと

- ペット保険の窓口精算（負担率と限度額の設計を検討中）
- 傷病名の記録（保険請求書類の作成に必要）

- iPad のカメラで一次元バーコードを読むこと（QRのみ。リーダーは使えます）
- 1台にまとめた場合、診察中に受付で会計を打つこと

## 含まれないもの

**VetssWeb（電子カルテ本体）は OpenVetss に含まれません。** 非公開の製品です。
両方をお使いの病院向けに連携用のファイルがありますが、そちらは VetssWeb と組み合わせて初めて動くもので、このリポジトリの対象外です。

OpenVetss は **VetssWeb がなくても単独で動きます。**

## 開発の背景

新規開発ではありません。

レジの入力文法とキー割当は、20年ほど前に動物病院向けに書かれ、実際の窓口で使われ続けてきたものです。当時まだ珍しかった非同期通信を使い、画面を再読み込みせずに明細が伸びていく作りでした。カルテの文例2,626件も、長年の診療から積み上がったものです。

今回やったのは、発明ではなく**移し替え**です。キー配置がテーブルにあり、マスタが名称だけを持ち、業務ロジックが1ファイルに集まっていた——元の設計が正しかったから移せました。

変わったのは置き場所だけです。サーバの中にあったものがタブレットの中に移り、それだけで、必要なものが専用機とサーバからブラウザ1つになりました。
